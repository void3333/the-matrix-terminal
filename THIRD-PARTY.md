# Componentes de terceiros

The Matrix é uma configuração independente para Windows. Os clientes do Codex e do Claude Code continuam sendo produtos da OpenAI e da Anthropic. A menção aos nomes não indica patrocínio ou afiliação.

O instalador baixa os aplicativos abaixo dos respectivos projetos. Os executáveis desses projetos não ficam no repositório.

| Componente | Origem |
| --- | --- |
| WezTerm | [wezterm/wezterm](https://github.com/wezterm/wezterm) |
| PowerShell | [PowerShell/PowerShell](https://github.com/PowerShell/PowerShell) |
| Git e Git Bash | [git-for-windows/git](https://github.com/git-for-windows/git) |
| Oh My Posh | [JanDeDobbeleer/oh-my-posh](https://github.com/JanDeDobbeleer/oh-my-posh) |
| Codex CLI | [openai/codex](https://github.com/openai/codex) |
| Claude Code | [Documentação oficial da Anthropic](https://code.claude.com/docs/en/setup) |

A fonte JetBrains Mono Nerd Font Mono é distribuída com a licença [SIL Open Font License](terminal/Fonts/OFL.txt).
